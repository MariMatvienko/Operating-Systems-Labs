# Как запустить

1. Скачай оба файла (`lab2_parallel.c` и `lab2_sequentially.c`) в одну папку.

2. Скомпилируй параллельную версию (нужна библиотека потоков):

   gcc -lpthread lab2_parallel.c -o lab2_parallel 

3. Скомпилируй последовательную версию:

   gcc lab2_sequentially.c -o lab2_sequentially

4. Запусти:

   - Параллельная — два параметра: количество потоков и количество перемешиваний:

     ./lab2_parallel <кол-во потоков> <кол-во перемешиваний>

     Например:

     ./lab2_parallel 4 100

   - Последовательная — один параметр: количество перемешиваний:

     ./lab2_sequentially <кол-во перемешиваний>

     Например:

     ./lab2_sequentially 100
